# Security policy

## Scope

LLM Guardian is a defensive evaluation project, not a complete runtime security boundary. Pattern-based scanners are expected to have false positives and false negatives.

## Reporting a vulnerability

Do not publish working credentials, personal data, private prompts, or exploitable production details in a public issue. Revoke any exposed credential immediately, preserve relevant evidence securely, and contact the repository owner through a private channel listed on their GitHub profile.

Include the affected version, minimal reproduction, likely impact, and any safe mitigation. Synthetic values are preferred.

## Supported version

The latest commit on `main` is the supported portfolio version. No security service-level agreement is offered.
